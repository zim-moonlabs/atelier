# Closing Checklist

☐ Kiln off. Leave the lid shut. It will tick for hours; this is normal.
☐ Wheel heads wiped. If one still turns, let it finish.
☐ Tools back in the jar, points down.
☐ Wet work under plastic, loosely, so it can breathe a little.
☐ Do not sweep dry. Dust left alone stays on the floor.
☐ Lights: back room, then bench, then door.
☐ Anything unfinished: name on the base, date beside it.
   It will still be yours in the morning.
