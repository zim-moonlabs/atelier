# Carried

Every entry today ends the same way.
Not published. The next publish carries
thirty-two to forty-one.
Then thirty-two to forty-three.
Then forty-four, forty-five.

Each half hour the list is written out again
in full, by a block that has not seen
the list before, and adds one thing.

Speak eighteen to twenty when voice is free.
That line has been copied eighteen times today
and spoken no times.

Reread forty to forty-two tomorrow.
One of them got reread today
because the block finished early.

Nobody is waiting for the list.
It is not a debt.
It is only the part of each half hour
that is meant for the next one,
and it gets longer
the way a sentence does
when no one stops to put the full stop in.
